Sky Web Dokümantasyonu

Kendi sitenizi yazın, .site uzantınız olsun. Bu sayfa Sky Web'in nasıl çalıştığını ve nasıl site yapacağınızı anlatır.

Sky Web nasıl çalışır

  1. Adres çubuğuna ornek.site yazarsınız.

  2. SkyBrowser bunu SkyDNS'e sorar: hangi GitHub deposu?

  3. SkyDNS depo adresini döndürür, örneğin kullanıcı/repo.

  4. SkyBrowser o depodan index.html, styles.css ve script.dart dosyalarını indirir.

  5. Engine HTML'i Flutter widget'larına çevirir, CSS'i uygular, script'i çalıştırır.

Yani siteniz bir sunucuda değil, GitHub deposunda durur. Sunucu tutmanıza gerek yok.

Dosyalar

Deponuzun kökünde ya da bir alt klasörde şu dosyalar bulunur:

  • index.html - zorunlu, sayfanın iskeleti

  • styles.css - isteğe bağlı, görünüm

  • script.dart - isteğe bağlı, buton ve zamanlayıcı davranışları

  • favicon.png - isteğe bağlı, sekme ikonu

İlk sayfanız

<html> <head> <title>Benim Sitem</title> <icon src="favicon.png" /> </head> <body> <h1>Merhaba</h1> <p>Bu benim ilk Sky sitem.</p> </body> </html>

Not: İkon için <link rel="icon"> değil, kendi <icon src="..." /> etiketimiz kullanılır.

Desteklenen etiketler

  • h1, h2, h3 - başlıklar

  • p - paragraf

  • div - kutu ve yerleşim

  • ul, ol, li - listeler

  • a - link görünümü

  • img - resim, src ile

  • input - metin kutusu, id ile

  • button - buton, onclick ile

Listelerde li içine doğrudan yazı yazmayın, içine p koyun.

CSS ve Satır İçi Stiller

İki seçici türü vardır: etiket adı ve nokta ile sınıf. Ayrıca HTML etiketlerinde satır içi style="..." özniteliği de desteklenir. id seçici yoktur, id sadece script için kullanılır.

h1 { color: white; font-size: 32px; } .uyari { color: red; }

Satır içi stil ve eleman gizleme (display: none) kullanımı:

<p style="display: none;" id="gizli_veri"></p> <div style="background-color: #333333; padding: 12px;">...</div>

display: none elemanı ekranda gizler ancak id'si script.dart tarafında (getText/setText) kullanılabilir kalır.

Renkler: hex (#ff0000, #f00) veya isim (red, blue, white, black, green, yellow, orange, purple, grey).

Yerleşim

Her div bir yerleşim kutusudur. display yazmanıza gerek yok, direction yeter.

.satir { direction: row; main-axis: space-between; cross-axis: center; gap: 12px; padding: 16px; background-color: #222222; }

  • direction: row veya column, varsayılan row

  • main-axis: start, center, end, space-between, space-around

  • cross-axis: start, center, end, stretch

  • gap: öğeler arası boşluk

  • padding: 16px ya da 8px 16px ya da 8px 16px 8px 16px

  • width, height: sabit boyut, div ve p için

  • display: none: elemanı ekranda gizleme

main-axis ve cross-axis, CSS'teki justify-content ve align-items yerine geçer.

Bağlantılar

a etiketiyle başka bir Sky sitesine gidebilirsiniz. href olarak domain yazın:

<a href="docs.site">Dokümantasyon</a>

Bağlantılar ayrı satırda olmalı, paragraf içine gömülemez. Dış adresler (http ile başlayanlar) henüz açılmaz.

Sayfa arka planı

Varsayılan arka plan siyah, yazılar beyazdır. Değiştirmek isterseniz:

body { background-color: white; }

Açık zemine geçerseniz yazı renklerini de kendiniz belirlemelisiniz.

script.dart

Butonlara ve zamanlayıcılara dinamik davranış eklemek için script.dart yazarsınız. JavaScript değil, gerçek Dart.

Sayfa yüklendiğinde main() fonksiyonu tanımlıysa otomatik çalıştırılır. Değişken durumları (state) sayfa açık kaldığı sürece fonksiyon çağrıları arasında korunur.

<input id="ad" placeholder="adınız" /> <button onclick="selamla">Selamla</button> <p id="cikti"></p>

Fonksiyonlar parametre almak zorunda değildir. Köprü fonksiyonları (getInput, setText vb.) ortamda küresel olarak hazırdır:

void selamla() { var ad = getInput('ad'); setText('cikti', 'Merhaba ' + ad); }

Script fonksiyonları (Köprüler)

  • getInput(id) - o id'li input'un mevcut değerini döndürür

  • getText(id) - o id'li elemanın mevcut metin içeriğini döndürür

  • setText(id, yazi) - o id'li elemanın yazısını günceller

  • get(adres, sonucId) - HTTP GET isteği atar, ham cevabı sonucId elemanına yazar

  • post(adres, govde, sonucId) - HTTP POST isteği atar, ham cevabı sonucId elemanına yazar

  • setTimeout(fonksiyonAdi, milisaniye) - belirtilen süre sonra fonksiyonu bir kez tetikler

  • clearTimeout(fonksiyonAdi) - bekleyen tek seferlik zamanlayıcıyı iptal eder

  • setInterval(fonksiyonAdi, milisaniye) - fonksiyonu periyodik tetikler (en az 50ms)

  • clearInterval(fonksiyonAdi) - periyodik zamanlayıcıyı durdurur

get ve post istekleri asenkrondur; beklemez, cevap geldiğinde ham HTTP yanıtı sonucId elemanına yazılır.

Domain alma

Siteniz hazır olunca GitHub'a yükleyin, sonra aşağıdaki bağlantıdan kaydınızı oluşturun.

domain.get adresine git

  • Domain: istediğiniz ad, örneğin blog

  • TLD: uzantı, örneğin site

  • Repo: kullanıcı/repo ya da kullanıcı/repo/klasör

Kayıttan sonra adres çubuğuna blog.site yazarak sitenizi açabilirsiniz.

Sınırlar

  • Linkler paragraf içine gömülemez, ayrı satırda olmalı

  • id seçici CSS'te çalışmaz, sadece script için

  • setText sadece p etiketlerinde çalışır

  • font-family, border, margin henüz yok

  • Yüzde (%) birimi yok, sadece px

  • Dal her zaman main kabul edilir
