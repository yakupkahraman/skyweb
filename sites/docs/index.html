Sky Web Dokumantasyon

Kendi sitenizi yazin, .site uzantiniz olsun. Bu sayfa Sky Web'in nasil calistigini ve nasil site yapacaginizi anlatir.

Sky Web nasil calisir

  1. Adres cubuguna ornek.site yazarsiniz.

  2. SkyBrowser bunu SkyDNS'e sorar: hangi GitHub deposu?

  3. SkyDNS depo adresini dondurur, ornegin kullanici/repo.

  4. SkyBrowser o depodan index.html, styles.css ve script.dart dosyalarini indirir.

  5. Engine HTML'i Flutter widget'larina cevirir, CSS'i uygular, script'i calistirir.

Yani siteniz bir sunucuda degil, GitHub deposunda durur. Sunucu tutmaniza gerek yok.

Dosyalar

Deponuzun kokunde ya da bir alt klasorde su dosyalar bulunur:

  • index.html - zorunlu, sayfanin iskeleti

  • styles.css - istege bagli, gorunum

  • script.dart - istege bagli, buton davranislari

  • favicon.png - istege bagli, sekme ikonu

Ilk sayfaniz

<html> <head> <title>Benim Sitem</title> <icon src="favicon.png" /> </head> <body> <h1>Merhaba</h1> <p>Bu benim ilk Sky sitem.</p> </body> </html>

Not: Ikon icin <link rel="icon"> degil, kendi <icon src="..." /> etiketimiz kullanilir.

Desteklenen etiketler

  • h1, h2, h3 - basliklar

  • p - paragraf

  • div - kutu ve yerlesim

  • ul, ol, li - listeler

  • a - link gorunumu

  • img - resim, src ile

  • input - metin kutusu, id ile

  • button - buton, onclick ile

Listelerde li icine dogrudan yazi yazmayin, icine p koyun.

CSS

Iki secici turu vardir: etiket adi ve nokta ile sinif. id secici yoktur, id sadece script icin kullanilir.

h1 { color: white; font-size: 32px; } .uyari { color: red; }

Renkler: hex (#ff0000, #f00) veya isim (red, blue, white, black, green, yellow, orange, purple, grey).

Yerlesim

Her div bir yerlesim kutusudur. display yazmaniza gerek yok, direction yeter.

.satir { direction: row; main-axis: space-between; cross-axis: center; gap: 12px; padding: 16px; background-color: #222222; }

  • direction: row veya column, varsayilan row

  • main-axis: start, center, end, space-between, space-around

  • cross-axis: start, center, end, stretch

  • gap: ogeler arasi bosluk

  • padding: 16px ya da 8px 16px ya da 8px 16px 8px 16px

main-axis ve cross-axis, CSS'teki justify-content ve align-items yerine gecer.

Sayfa arka plani

Varsayilan arka plan siyah, yazilar beyazdir. Degistirmek isterseniz:

body { background-color: white; }

Acik zemine gecerseniz yazi renklerini de kendiniz belirlemelisiniz.

script.dart

Butonlara davranis eklemek icin script.dart yazarsiniz. JavaScript degil, gercek Dart.

Butonda onclick ile fonksiyon adini verirsiniz:

<input id="ad" placeholder="adiniz" /> <button onclick="selamla">Selamla</button> <p id="cikti"></p>

script.dart icinde ayni isimde bir fonksiyon tanimlarsiniz. Her fonksiyon uc parametre alir, sirasi degismez:

void selamla(Function getInput, Function post, Function setText) { var ad = getInput('ad'); setText('cikti', 'Merhaba ' + ad); }

Script fonksiyonlari

  • getInput(id) - o id'li input'un icindeki yaziyi verir

  • setText(id, yazi) - o id'li p etiketinin yazisini degistirir

  • post(adres, govde, sonucId) - adrese POST atar, cevabi sonucId'ye yazar

post beklemez, cevap gelince sonuc kendiliginden yazilir. await kullanmaniza gerek yok.

Domain alma

Siteniz hazir olunca GitHub'a yukleyin, sonra adres cubuguna domain.get yazip kaydinizi olusturun.

  • Domain: istediginiz ad, ornegin blog

  • TLD: uzanti, ornegin site

  • Repo: kullanici/repo ya da kullanici/repo/klasor

Kayittan sonra adres cubuguna blog.site yazarak sitenizi acabilirsiniz.

Sinirlar

  • Linkler henuz tiklanabilir degil, sadece gorunum

  • id secici CSS'te calismaz, sadece script icin

  • setText sadece p etiketlerinde calisir

  • font-family, border, margin henuz yok

  • Dal her zaman main kabul edilir

Sky Web hobi olarak gelistiriliyor, eksikler zamanla kapanacak.
